## Como usar esses prompts

**Para Midjourney v6:**
- Cole o prompt no Discord do MJ depois de `/imagine`
- Use os parâmetros recomendados (--ar, --style, --v)
- Gere 4 variações, escolha melhor

**Para Nano-banana (Google):**
- Cola o texto do prompt diretamente
- Sem parâmetros — Nano interpreta o style description

**Para DALL-E 3 (ChatGPT/Plus):**
- Cola o texto traduzido em inglês
- DALL-E entende natural language melhor que MJ

**Tipo de imagem ideal:**
- Hero: 16:9 horizontal (1920x1080) ou 9:16 vertical mobile (1080x1920)
- Cards lifestyle/region: 4:3 ou 1:1 (700x700)
- Section accents: 16:9 horizontal

**Paleta da marca pra mencionar nos prompts:**
- Champagne gold #B89E68
- Cream beige #F5EFE5
- Soft black #1A1818
- Warm off-white #FAF8F4

## PIPELINE DE TRABALHO RECOMENDADO

### Opção A — Fast iteration (1-2h, custo zero)
1. Use Nano-banana (Google AI Studio) — grátis, ilimitado
2. Cole cada prompt, gera 4 variações, escolha melhor
3. Save todas em `/Users/brunosilva/Downloads/heritage_signal_deploy/miami-ia/img/`
4. Substitua URLs do Unsplash no index.html pelos paths locais
5. Push pra Vercel

### Opção B — Premium quality (1-2h, ~$30)
1. Use Midjourney v6 (Discord) — $10/mês plano básico
2. Adicione parâmetros: `--ar 16:9 --style raw --v 6`
3. Use `/upscale` na melhor variação
4. Download em 2048px+
5. Otimize com tinypng.com (reduz 70% tamanho sem perder qualidade)
6. Substitua URLs

### Opção C — Híbrido (recomendado)
1. Hero + Region cards (alta exposição): Midjourney v6 ($)
2. Lifestyle cards + section accents: Nano-banana (grátis)
3. Background blurry/abstrato: Nano-banana
4. Mix custo + qualidade
