# Miami IA — Heritage Signal

Landing page de matchmaking de imóveis em Miami via IA. Lead responde 7 perguntas, sistema retorna 4 imóveis matched.

**Stack:** HTML/CSS/JS vanilla + Vercel + Formspree

**Fluxo:**
1. Hero "Encontra teu imóvel em 30 segundos"
2. 7 perguntas (budget, family, purpose, lifestyle, schools, timeline, structure)
3. Loading animation "Analisando 305.000 imóveis..."
4. Resultados: 4 imóveis matched com % de match
5. Email capture pra liberar PDF detalhado + tour virtual
6. Thank you page
